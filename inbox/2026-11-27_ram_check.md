# RAM check before the order: 4 x Kingston KVR56U46BD8-64 (256 GB), 27 Nov 2026

## Easy read

**Verdict: OK to order, with conditions.** About 85 % sure. The board, the CPU and the BIOS all support 4 x 64 GB. Nobody has confirmed that this exact module was tested on this exact board.

1. No BIOS update is needed first. Installed 1686 is newer than 1006, the first version that supports 4 x 64 GB.
2. Before ordering, ask the supplier to send all four modules from the same batch, with the same label and revision. This is a request, not a blocker.
3. Take out both current 32 GB modules and fill all four slots with the new ones. Do not mix old and new.
4. First boot: the screen may stay black for several minutes while the memory trains, and it may restart once or twice. Do not switch it off.
5. In BIOS, leave memory on Auto with EXPO off. Expect 3600 to 5200 MT/s, not 5600.
6. Run a memory test overnight (MemTest86 from USB) before trusting any solver results.
7. Keep the old 2 x 32 GB modules until the test passes.

Not confirmed: whether the module is on Kingston's or ASUS's tested list for this board (both pages were closed to me, or showed no 64 GB entries). The supplier's configurator claim is still unchecked.

**(d) Known problems with 4 x 64 GB on AM5** (from a forum / third party)
- Long memory training at first boot and after a CMOS clear. Four modules take about twice as long as two, and dual-rank modules take longer still. If training fails, the board can take 5 to 6 minutes and fall back to JEDEC speeds. https://www.techpowerup.com/forums/threads/am5-memory-training-length.336043/ ; https://www.guru3d.com/story/asrock-x670e-steel-legend-motherboard-memory-training-requires-hundreds-of-seconds-at-first-boot/
- "Memory Context Restore" in BIOS shortens later cold boots; some users report instability with it on. Leave it at the default until the memory test has passed. https://www.techpowerup.com/forums/threads/am5-boot-times-improve-radically-with-memory-context-restore-enabled.322285
- A BIOS update before fitting is needed only on BIOS older than about AGESA 1.2.0.3a or 1.2.0.3e. That does not apply here (1686). https://www.tweaktown.com/news/105825/msi-releases-amd-agesa-1-2-0-3e-bios-officially-supports-4-64gb-sticks-up-to-256gb-ram/index.html
- No public report of 4 x 64 GB on this exact board was found.

**(e) Four single modules instead of a kit of four** (from a forum / third party)
- No kit of four 64 GB is offered. Two kits of two are not a tested set of four either, so the FURY alternative is no safer on this point.
- The risk with single modules is a different chip or PCB revision under the same part number. Modules from one batch, run at JEDEC speed, keep that risk low. https://evezone.evetech.co.za/quick-bytes/mixing-ram-kits-matched-kits-exist-can-go ; https://forums.tomshardware.com/threads/is-there-any-reason-to-buy-a-kit-instead-of-2-separate-identical-ram-sticks.3671050
