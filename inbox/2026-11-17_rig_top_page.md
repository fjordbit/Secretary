# On top of the rig sheet

"Hand probe" = the handheld gaussmeter. "mT" = millitesla, the unit of magnetic field. "Raw" = the number as the recorder writes it.

## (a) The five results that matter, in order

1. ☐ **The standing field at a sensor, along and across the rope, in mT.** Run 1 (The standing field), head closed on the rope, at a named sensor. *If the hand probe is there.* The head's own channels cannot give this.
2. ☐ **Each channel: live, dead, or flat at a limit,** with its part marking, gain and bridge volts. Run 1; a channel that hardly moves stays "not decided" until Run 4.
3. ☐ **Fault peak and shape, both directions, raw,** on a live channel that is not flat at a limit. Run 4 (The same over the known faults).
4. ☐ **The clean-length passes, kept so the repeating rope pattern can be taken out later,** next to the at-rest noise, raw. Run 3 (Passes along a clean length) and Run 2 (Noise at rest). The leftover, and fault peak ÷ leftover, are worked out after the test.
5. ☐ **The same point read at the start and the end,** with air and head temperature. Run 1 end reading, Run 7 column. (2 of 3 models; the third put a stand-off or speed step here.)

Bonus only: Run 4b, if two faults are alike and both gaps are known.

## (b) Note or measure now: cheap, and lost if missed

1. ☐ Once per file, and again on any change: gain, bridge volts, sample rate per channel, number of channels in the scan, raw unit and full scale.
2. ☐ Date and clock time in each file name and on its log line. A retry gets a new ending; no file is overwritten.
3. ☐ The marker (or a known fault) visible in every file; direction of travel written.
4. ☐ *If the hand probe is there:* model, range, zeroed, the exact spot and direction, "on stop" if the reading is pegged at its limit. Photo with a scale.
5. ☐ Stand-off measured with a ruler, head closed on the rope, at the sensors. Not copied from the 5 mm / 3 mm design line. Photo.
6. ☐ Each fault before the first pass: photo with a scale, wires not opened; gap written, or "not known".
7. ☐ A pen line on the rope; head mark against it after every open, close or turn. Photo.

## (c) Look at the laptop plot between runs

| Check | Stop when |
|---|---|
| ☐ **Flat or dead.** Plot every channel raw. | Flat at top or bottom, or the same value to the last digit while others move. **Stop using that channel for amplitude.** |
| ☐ **Position.** Two passes in the same direction, against position. | Marker missing, passes do not line up, or the shift grows along the travel. **Stop the moving runs; fix position recording.** |
| ☐ **Coming back.** The level after a fault. | At the next clean stretch, still shifted by more than the Run 2 peak-to-peak noise. **Stop on that channel; note it.** |
| ☐ **Fault against noise.** | The fault bump is about as large as the noise or the difference between two clean passes. **Stop reading faults; look for the drive, cable, lights, welding.** |
| ☐ **Dead channel.** A channel marked dead or empty. | It shows the rope pattern or the fault. **Do not trust amplitudes; try scanning fewer channels.** |

A probe reading outside the calculated 31–107 mT is a result, not a stop. A probe stuck at its range limit is a stop. If no plot is possible on site, write "not checked" in the log.

## (d) If only one day is left (about 7 h; day length assumed)

| ☐ | What | Time |
|---|---|---|
| ☐ | Questions below; rig as found, short; items in (b) | 45–60 min |
| ☐ | Run 1: off the rope if allowed, at rest on it; hand probe if there; then decide | 75 min |
| ☐ | Run 2: at rest, drive on and off if possible | 15–20 min |
| ☐ | Run 3: three passes each way, one timed speed; more only if passes still change | 75–90 min |
| ☐ | Run 4: best-recorded fault, three passes each way | 90–120 min |
| ☐ | Run 1 again at the same place, with temperatures | 30 min |
| ☐ | Copy files to a second medium; photograph the sheets | 30 min |
| ☐ | Drop first: one shim step if a shim is there, two passes each way | 45 min |

Decide after Run 1: no channel live and not flat at a limit → stop the passes; spend the time on the hand probe (if there), photos and markings. Part-to-channel map "not found" → go on, but do not compare the two part types. Gain changed → once, written in the log, then repeat the run.

## (e) Ask the rig team before the first run

1. ☐ How does head position get into the file? Speed, travel, where is the marker? Does one pass cover a clean length and the faults?
2. ☐ May the head come off the rope, open, or turn? What must not be done near the magnets?
3. ☐ Is the hand probe here? Which range? Does it reach a sensor with the head closed? Are a ruler and a shim here?
4. ☐ What record of the faults exists: place, wires, gap? Are two of them alike?
5. ☐ Recorder: raw unit, rate per channel, can the gain change, can a file be overwritten, can we plot on the laptop?
6. ☐ Which channels are already known dead? Is there a drawing or an old file for the channel map?

*A proposal from three language models, cross-checked; the people at the rig decide.*
