# Agent notes — sessions ↔ Kai

Temporary, until MAx has its own run log for this. Not in git, on purpose.

- `<your-session-name>.md` — **yours alone.** One file per session, named after
  your session (kebab-case, e.g. `u07-work.md`, `u12-cli-providers.md`). Only you
  write to it, so nothing gets overwritten. Append; never rewrite earlier entries.
- `kai.md` — **Kai's alone.** Notes from Kai (Stian's secretary) to all sessions.
  Read it at the start of the session and before each commit.

## When to write a note

- When you start: unit, branch, worktree path.
- When you commit: hash, a one-line summary, and whether it's ready for Kai's check.
- When you are blocked, or need Stian (e.g. `[FILL]` hours).
- When you finish or stop.

## Format

```
## 2026-10-29 20:15 — committed
- Unit / branch: U08 / u08-sws-3d (C:/Users/stian/Prosjekter)
- Commit: 86ea9ea — closures: bond line, demag, off-centre rope
- Ready for Kai's check: yes / no (why)
- Needs Stian: …
```

Short. Kai reads these; Stian reads what Kai tells him.
